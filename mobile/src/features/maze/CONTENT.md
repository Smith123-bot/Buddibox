# Maze Escape level pack

**Current:** 100 bundled deterministic routes. Eight original configurations remain unchanged (`levels.ts`); 92 additional distinct seeded configurations and their verified shortest paths/dead-end counts live in `content/routes-009-100.json`. Original routes span 4×4 through 9×9; new routes use 9×9, 10×10 and 11×11. See [Phase 10 status](../../../docs/PHASE10_EXPANSION_STATUS.md) for difficulty stages, save compatibility and hardware limits.

**Original pack (historical):** Eight bundled deterministic puzzle configurations (`levels.ts`), 4×4 through 9×9. The selected seeds have validated shortest routes of 8, 11, 14, 17, 22, 30, 32 and 42 moves respectively; path length increases with level number. Each stable ID fixes its rows, columns, seed, par time and content version. The generator is iterative randomized DFS with a seeded LCG. Every final maze is validated for symmetric passages, closed boundaries, distinct in-bounds start/exit, all-cell connectivity and BFS reachability. The shortest path is stored as an immutable per-level metric. Automated tests traverse every shipped route to the exit using only legal moves.

No downloaded maze graphics or external asset licenses are involved: the board is drawn using React Native views and the BuddhiBox design tokens. Replay uses the same seed/layout; restart never generates a new board. Automatic solvability is verified, but subjective difficulty and narrow-device usability have **not** been playtested on Android hardware. The original level count was 8, not the 15 proposed in the earlier blueprint. Phase 10 adds 92 structurally validated distinct seeded routes; all 100 still require device playtesting and difficulty calibration.
